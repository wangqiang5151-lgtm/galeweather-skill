# 风电与光伏字段说明

以下含义依据仓库候选清单；字段存在不代表已授权或已通过线上验证。current支持情况尚未给出。具体字段名大小写必须保留。

## 风电

| 字段 | 单位与清单含义 | 接入前需要确认 |
|---|---|---|
| wind_speed_70m | m/s，70米风速 | 高度基准；瞬时/时段平均；垂直插值方法 |
| wind_direction_70m | °，70米风向 | 来向/去向、零度基准、顺逆时针、静风处理 |
| wind_speed_100m | m/s，100米风速 | 是否为当前Key开放层高 |
| wind_gusts_10m | m/s，10米阵风 | 阵风统计时段；不能替代轮毂高度平均风速 |
| wind_speed_850hPa | m/s，850hPa气压层风速 | 气压层不是固定离地高度；候选清单标记无历史支持 |

风向属于周期变量，不能把359°与1°简单平均成180°。本客户端只返回接口数据，不执行业务平滑或修正。

PDF与Word的层高范围存在冲突：候选清单列10—200m每10m，而另一来源建议10、30…170m并将200m列为不支持示例。请以服务方核验矩阵及实际Key权限为准，不能直接承诺所有层高可用。

## 光伏

| 字段 | 单位 | 清单含义 |
|---|---|---|
| shortwave_radiation | W/m² | 水平面总短波辐照度，GHI |
| direct_normal_irradiance | W/m² | 法向直接辐照度，DNI |
| direct_radiation | W/m² | 水平面直接辐照度，不是DNI |
| diffuse_radiation | W/m² | 水平面散射辐照度，DHI |
| global_tilted_irradiance | W/m² | 倾斜面总辐照度，GTI |
| cloud_cover | % | 总云量 |
| relative_humidity_2m | % | 2米相对湿度 |
| clear_sky_ghi / clear_sky_dni | W/m² | 清单称“疾风大模型GHI/DNI”，定义待确认 |

不要仅凭clear_sky字段名认定它是晴空辐照，也不要直接等同于全天候GHI/DNI。GTI需明确倾角和方位角采用什么值；当前CLI没有这两个输入参数。

带_instant的辐照字段在清单中表示时刻值，部分标记不支持历史；不带后缀的字段仍需服务方明确平均时段和时间戳代表时段起点还是终点。

W/m²是辐照度，不能直接当作Wh/m²。只有确认数值代表整个15分钟时段的平均辐照度时，才可用“数值×0.25小时”计算该时段辐照量。15分钟输出间隔本身不能证明这一条件成立。

保留现有Skill的处理原则：区分水平直射与DNI，不强制DNI≤GHI，也不强制直接辐照度≥散射辐照度，不擅自修剪接口数据。夜间0值与缺测必须依据时间和缺测规范区分。

## 数据用途与边界

气象字段可作为功率预测的输入，但不直接等于场站功率或交易收益。历史气象数据也不能自动作为“当时可获得的预测”进行无泄漏回测。

网格分辨率、更新频次、站点观测属性、15分钟是否插值以及准确率评估，当前仓库没有充分证据。对外评估应注明站点、样本日期、预测提前量、指标与缺测规则，不使用未经验证的精度承诺。
