# API试用、额度与升级

通过[README联系方式](../README.md#联系与试用)申请。当前仓库不提供自助注册、发Key、充值或用量查询接口。不要猜测存在这些接口。

## 申请时提供

用途（风电/光伏/一般气象）、区域或坐标、字段及层高、预测/历史/当前类型、历史日期范围、点位数、每日频次，以及试用验收目标。无需提供场站私密数据或在公开渠道发送Key。

## 授权确认卡

以下是服务方应随Key交付的确认表，空项代表待确认，不是默认无限制或默认免费。

| 项目 | 当前仓库能确认的内容 | 交付时须填写 |
|---|---|---|
| 地址 | 客户端默认HTTPS；生产上线状态未验证 | 正式基础地址及验证日期 |
| 有效期 | 服务端控制 | 开始/到期时间和时区 |
| 接口 | 客户端支持四模式 | 实际开放路径 |
| 坐标 | 客户端单点查询 | 国家/区域/站点、精度、坐标系 |
| 字段 | 235项候选，不代表授权 | 允许字段、层高及各接口支持情况 |
| 预测跨度 | 客户端1—15天 | 实际套餐支持跨度 |
| 历史范围 | 客户端校验日期格式及先后 | 最早日期、数据延迟、单次天数 |
| 配额 | 尚无确定数值 | 每日/月额度、计量单位、重置时区 |
| 限流 | 客户端遇限流不自动重试 | 每秒/每分钟限制、并发数、恢复条件 |
| 失败计量 | 未说明 | 参数错误、鉴权失败、空数据是否计费 |
| 辅助接口 | variables也需Key | 是否计费、清单是否按Key过滤 |
| 使用权 | 依服务授权 | 内部评估/生产/转售/再分发权限 |
| 支持与升级 | README二维码 | 联系方式、响应约定及升级办理方式 |

## 计量示例

100个点×每日2次=每日200次单点HTTP请求。如果每次含3个字段，是否按200次请求、600个“点×字段”单位，或按其他规则计量，必须由套餐明确。以上仅是算例，不代表本服务的计费规则。

重复请求、失败重试、长历史拆分和variables查询均可能影响额度。客户端不自动重试；遇429后先确认是频率限制还是日额度耗尽，再按服务方规则恢复，不能一律理解为等几秒即可继续。

## 试用验收与转正式

先用一个授权点位、一天、少量字段验证：鉴权成功、字段齐全、时间和单位正确、缺测可识别；再按授权扩大范围。记录接口、字段、时间范围和验收结果，不记录Key。

正式使用前确认额度、更新频率、字段支持、使用权及支持约定。试用Key到期或权限不足时联系服务方续期或升级；本仓库没有已发布价格表，不以候选字段数或客户端默认参数代替采购承诺。
